## Download

Get the latest **`ModernTimer.exe`** from the [Releases](../../releases/latest) page, then double-click it. That's it.

Requires Windows 10 or 11.

## Features

- **Timer** with a glowing progress ring. Set the time by scrolling over hours/minutes/seconds, typing digits, or using the presets (1, 5, 10, 25 min, 1 h). `+1m` extends a running timer.
- **Stopwatch** with lap splits (best lap in green, worst in red).
- **Soft alarm**: a gentle "beep beep" that repeats until dismissed, and the taskbar button flashes.
- **Four views**
  - Normal window
  - **Compact**: a small square with only the time and play/stop buttons
  - **Bar**: a thin borderless progress strip at the bottom of the screen
  - **Full screen**
- **Themes**: Aurora (colorful) and Minimal (pure black and white).
- **Always on top** pin, so it can stay over your other windows.
- Taskbar progress, remaining time in the title, per-monitor DPI support.
- Portable: settings are saved in `ModernTimer.ini` next to the exe. Delete it and nothing is left behind.

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| Space / Enter | Start / pause |
| R | Reset |
| Tab | Switch Timer / Stopwatch |
| L | Lap (stopwatch) |
| 0-9, Backspace | Type a time (timer) |
| Up / Down | +/- 1 minute (timer) |
| T | Always on top |
| C | Compact view |
| B | Bar view |
| F11 | Full screen |
| M | Switch theme |
| Esc | Leave bar / full screen, or reset |

In **bar** view: drag to move, double-click to go back, middle-click to start/pause, and right-click for a menu (right-click works in every view).
